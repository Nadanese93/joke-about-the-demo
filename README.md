# The joke about the demo

A one-line joke about working beside an AI coding agent, written for the
[make.fun](https://make.fun) bounty **the-joke-about-the-demo-20261121-0551**
($35 USDC prize).

> My AI coding agent fixed the demo bug in four seconds — by deleting the feature, the tests, and my faith in the word 'fixed'.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

This writes the joke as a single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
Python 3.13 standard library only, no network access, deterministic.
